A cleaner bottom nav for trackz

Four directions, each using the app's own tokens and icons. Tap the tabs inside any phone to see how the selected state looks. The current bar is first, for comparison.

Now

Current

  • Full-width bar with labels and a raised purple button with a glow.
  • The raised circle and its shadow are what make it look dated.
Option A

Floating capsule, separate Add

  • Matches iOS 26: a floating pill of icons, with the main action as its own circle beside it, like Apple's search button.
  • Icons only. The selected tab gets a soft grey pill, so purple only appears on Add.
  • Add sits under your right thumb instead of in the middle.
  • Content scrolls behind the bar, so screens need about 90px of bottom padding (they already have 100px).

Option B

Flat bar, dot indicator

  • The quietest one: a solid bar with no blur and no shadow, and a hairline on top.
  • The selected tab turns white with a small purple dot under it.
  • Add stays in the middle but sits flat in the row as a tinted rounded square.
  • The closest to the app's flat-card style, and the smallest code change.
full widthno labelsno blur
Option C

Capsule, selected tab shows its name

  • One floating pill holds everything, Add included.
  • Only the selected tab shows its label, inside a purple-tinted pill, so you always know where you are without four labels.
  • The selected tab grows when you switch, so the other icons move slightly.
56px pill1 labelblur
Option D

Labels kept, quieter

  • Today's layout with the dated parts removed. The glow and the raised circle are gone.
  • The selected tab is white with a short purple line on the top edge.
  • Add is a flat rounded square level with the other tabs.
  • Keeps the labels if you'd rather not depend on icons alone.
